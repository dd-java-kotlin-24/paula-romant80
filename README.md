## Summary

**P.A.U.L.A.** is a **multi-user**, offline-first Android task manager, daily habit companion, and uplifting lifestyle organizer engineered exclusively in **Kotlin**. Developed in loving memory of Paula Elizabeth Kleczka—who championed an organized living space, folded blankets, and caring for family—the application bridges structured productivity with genuine personal connection for **any user**.

The app combines customizable to-do lists and recurring habit checklists with an interactive 2D companion avatar that provides real voice encouragement throughout the day. Engineered with **multi-user architecture**, individuals, roommates, or family members can each maintain their own private chores, routines, and habit streaks on a shared device. Users check off daily routines—like tidying rooms, folding blankets, or personal to-dos—and receive spoken affirmations, visual milestone celebrations, and accessible subtitles as goals are achieved. It is designed to be an encouraging, grounded organizer that makes staying on top of daily life feel empowering and uplifting.

## Key Features

- **Multi-User Profile Segregation:** Secure account support isolating tasks, routines, and streak history by authenticated user.
- **100% Idiomatic Kotlin:** Built with Kotlin Coroutines, reactive `StateFlow` / `Flow`, Room ORM via KSP, and Hilt dependency injection.
- **Daily Habit Streaks & Chores:** Customizable recurring routines and categorized to-do lists with swipe-to-complete gestures.
- **Paula's Spoken Voice Encouragement:** Authentic, restored audio affirmations and cheerful reminders paired with live on-screen subtitles.
- **Camera Proof of Completion:** Capture photo verification of clean spaces and completed chores directly to your habit history.
- **100% Offline-First Privacy:** All personal data is securely preserved on-device in a relational SQLite database (3NF).
